# 発展課題（S6で早く終わった人向け）

検索ツールで合格条件の3つがそろったら、ほかのツールも作って、エージェントに渡してみてください。ツールが増えると、LLMは質問ごとに「どのツールを呼ぶか」「呼ばないか」を自分で決めます。その決め方は、関数の名前と docstring の書き方で変わります。

作り方は検索ツールと同じです。関数を書いて、`my_agent/agent.py` の `tools=[...]` に足します。

## ツールの例

どれから作ってもかまいません。自分で思いついたツールでも大丈夫です。

| ツール | こんな質問で呼ばれるか試す | 手がかり |
| :-- | :-- | :-- |
| 自分が書いたQAだけを探す | 「42 Tokyoの大変なところは何ですか？」 | `search(query, k)` の結果には、どのファイルのQAかを表す `source` が入っている。`my_qa.csv` のものだけを残して返す |
| 答えられる質問の一覧を返す | 「どんなことに答えられますか？」 | `lib.rag` の `qa_files()` と `load_qa(paths)` で、登録したQAを読める |
| 学習時間を計算する | 「週35時間を半年続けると、全部で何時間ですか？」 | 引数に数を受け取り、計算した結果を返す |
| 今日の日付と曜日を返す | 「今日は何曜日ですか？」 | Pythonの `datetime` を使う |

## 試してほしいこと

- ツールを足したら、まず `python try_tool.py ツール名 引数` で関数だけを呼んで戻り値を確かめる。それから、そのツールが呼ばれそうな質問を `python ask.py "質問"` で聞き、画面の「[1] 調べる」で、どのツールが呼ばれたかを見る。
- 呼ばれてほしいのに呼ばれないとき、別のツールが呼ばれるときは、docstring の「何をするツールか」「いつ使うか」を書き直して、もう一度聞く。
- 検索ツールと、自分が書いたQAだけを探すツールのように、役割が近いツールを2つ並べると、LLMが迷う様子が見えやすい。

## 気をつけること

- キーが要る外部のWebサービスを呼ぶツールは作らない（今日配っているのはOpenAIのキーだけ）。
- S7の質問（「42 Tokyoで学ぶと、どんな力が身につきますか？」）にも、作ったツールが呼ばれるかもしれません。それで回答が変わるのはかまいません。S7では、そのまま聞いた回答を見せてください。
